# Requirements
- Qt6
- CMake >=4.0
- C++23 

# Building
After installing everything just do 

`cmake -B build`

`cmake --build build`

and you can find the executables in the build directory

# Running
Run `./build/server/server` as sudo

Run `./build/client/client` normally
